巴黎手帐 / Paris Pocket · 2026.12.7–14
================================

这是一款无需 App Store 的轻量 PWA 网页 App。
包括：8 天行程、景点的实际坐标与 Apple 地图跳转、在线地图、预订勾选、每日/酒店/航班备注、备份导入导出，以及离线浏览行程。

【最快发布方法：Netlify Drop】
1. 将 paris-pocket-pwa.zip 解压为文件夹（解压后应看到 index.html、app.js、trip-data.js 等）。
2. 用电脑浏览器打开 https://app.netlify.com/drop 。
3. 按页面提示将解压出来的整份网站文件夹拖进去发布，得到一个 https://xxx.netlify.app 地址。
   页面及免费额度规则可能随 Netlify 调整；如果需要持久更新同一个域名，建议登录并在自己的 Netlify 账号中管理这个站点。
4. 用 iPhone Safari 打开这个 HTTPS 地址，点「分享」→「添加到主屏幕」→打开「以 Web App 方式打开」（如有）→「添加」。
5. 从主屏幕打开「巴黎手帐」，即可像独立 App 一样使用。

【后续更新】
和 ChatGPT 继续完善日程后，可要求它更新这个项目的 trip-data.js，生成新版本。
如果同时更新了前端代码，连同 app.js / styles.css 一并替换。
将更新的文件重新部署到【同一个】Netlify 站点和网址，手机端联网重新打开后就会看到新行程。
如果网站有较强缓存，请修改 sw.js 第一行附近的 CACHE_VERSION，例如从 v1 修改为 v2 后再发布。
重点：用户自己的勾选和笔记保存在同一站点域名下的当前设备浏览器。不要随意更换网址；换设备/网址前请在「旅行卡片」中导出备份，再导入。

【重要区别】
- 行程中的时间是拟定计划，不是已预订的机票、门票或酒店。
- App 不会自动替你购票、订房或实时改动景点营业时间。
- 互联网地图需联网。离线仍可查看行程文字、预约清单和此前保存的笔记。
- Apple 地图标注的是景点本身，不保证为具体入口、导游集合点或码头上船口。
- 如果只是双击本地 index.html 文件打开，能预览部分内容，但不能保证 iPhone 主屏幕安装及离线 PWA 功能；必须部署 HTTPS 网站。

技术结构：index.html 页面 | styles.css 样式 | app.js 功能 | trip-data.js 日程数据 | manifest.webmanifest iPhone 安装元数据 | sw.js 离线缓存 | assets/ 图标。
